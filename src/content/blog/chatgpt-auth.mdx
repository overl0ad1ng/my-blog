## Orca

其实最开始，我不太习惯用 Codex，而是用 CLI。因为前段时间的 Codex Desktop 优化不太好，经常占用非常多的内存资源。

于是我就开始用 [Ocra](https://www.onorca.dev/)，这个项目还挺不错，是一款值得关注的 ADE。

它可以连接手机 App，这是挺不错的一点。

但其实也有一些短板吧，Ocra 的文件编辑器其实有点简约了，它本身没有 Language Server 什么的，也就没有智能索引之类的 IDE 功能。

这就不得不导致我同时打开 Orca + Zed 才能在关键时刻修改代码。

## 手机 ChatGPT 认证

手机上的 ChatGPT 可以连接 Codex，可以查看任务的详情，也可以进行对话。但是问题就出现在这里：

**我手机上的 ChatGPT 登录过期了**

我需要重新登录，这倒也不是什么麻烦事，重新登录一下就行了呗。

**问题出现在这里**

因为我没有海外手机号，所以是使用的一次性的验证码接收器。我觉得这没什么好说的，绝大部分国内注册 Codex 的人都是这样弄的，
所以这就不得不启用「高级账户安全」设置。通过这个设置，关掉手机验证码，打开两个 Passkey。

第一个用的是 Windows Hello，也只能在我的 Windows 上使用，第二个，需要你用移动设备注册一个 Passkey。

我使用的是小米手机，我直接用小米的相机扫描了 Passkey 注册的二维码，因此，这个 Passkey 是注册在小米系统上的密码管理工具 —— 关键原因。

然而，我发现 openai 的 passkey 挑战貌似不兼容小米的 Passkey。即便系统的生物（指纹）识别认证成功了，但是 passkey 成功的反馈并没有被 openai 的 auth 页面接收。

> 最开始我并不知道是小米密码管理工具的问题，这是后来一步步测试才发现的

我一直就卡在这里。
